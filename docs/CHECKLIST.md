# 수동 QA 체크리스트 (배포 전 두 브라우저로)

- [ ] 가입: 공백 포함 이름 → 공백 제거되어 표시. 같은 이름 재가입 → "이미 있는 이름입니다". 5자 비밀번호 → 거부.
- [ ] 로그인 실패 메시지 / 로그아웃 후 새로고침해도 로그인 화면.
- [ ] 새 의뢰: 담당자·새 키워드·제목만으로 제출 가능. 담당자 큐에 순번 1, 이모지·프로젝트·의뢰자 표시.
- [ ] 마감 지난 의뢰 빨간 배경. 마감 없는 의뢰 정상.
- [ ] 첨부 20MB 초과 차단 / 이하 업로드 후 상세에서 링크 열림.
- [ ] 담당자: 진행중 → 완료(메모·결과 파일). 대기에서 바로 완료도 가능.
- [ ] 반려: 사유 없이 불가, 사유 있으면 빨간 박스로 표시.
- [ ] 넘기기: 상대 큐 맨 뒤 + 대기 상태. 원 담당자는 더 이상 버튼 없음.
- [ ] 의뢰자: 대기 중 수정·취소 가능. 진행중 되면 버튼 사라짐.
- [ ] 제3자: 상세 열람·댓글만 가능.
- [ ] 댓글: 본인 것만 삭제. 관리자는 전부.
- [ ] 키워드: 추가·이름 변경·삭제(→미분류). 미분류 고정.
- [ ] 관리자: 관리 버튼, 사용자 삭제(admin_delete_user 함수) → 탈퇴자 표시, 의뢰 삭제.
- [ ] 실시간: 다른 브라우저 변경이 1초 내 반영.
- [ ] 댓글 입력 중 다른 브라우저가 상태를 바꿔도 쓰던 글이 남아 있고, 등록 후 최신 상태로 갱신.
- [ ] 모바일 폭(400px)에서 가로 스크롤 없음.
- [ ] Supabase 일시정지 상태에서 빨간 배너.
- [ ] 연결 끊김: 네트워크 차단 시 빨간 배너가 뜨고 30초마다 재연결을 재시도한다.
